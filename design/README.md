# Design references

The implemented visual direction is **Modern Botanical / editorial**: a warm ivory
foundation, deep pine, one restrained terracotta accent, Ibarra Real Nova headings with
Public Sans body text, soft warm-tinted shadows and no heavy borders.

| File | Status |
|---|---|
| `mentora-editorial-direction.html` | **Current.** The locked direction the frontend implements. Its tokens are ported to `frontend/src/styles/tokens.css`. |
| `mentora-design-language.html` | **Superseded.** The earlier "fluid, restrained neo-brutalism" exploration (paired with `../02-design-language.md`). Not what was built. |
| `screenshots/01-…04-*.png` | Superseded — renders of the neo-brutalist exploration above. |
| `screenshots/editorial-*`, `refined-*`, `sharp-*`, `v2-*`, `dense-*`, `contact-sheet.png`, `card-explore-zoom.png`, `verify-card-explore*.png` | Intermediate iterations while refining the editorial direction. Kept as design history; the HTML file above is the reference. |

These are design references, not documentation of the running app. For how the product
works and how it is built, see the [root README](../README.md).
